# Jaspreet Singh — Wizarding Portfolio

A responsive, static portfolio website built with HTML, CSS and vanilla JavaScript. No backend is required.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive visual design and animations
- `script.js` — mobile navigation, scroll reveal, active navigation and mailto contact form
- `assets/jaspreet-singh.png` — profile photo supplied for the portfolio
- `resume/Jaspreet_Singh_Resume.pdf` — supplied resume

## Run locally
Open `index.html` in a browser, or serve the folder using any static server.

## Deploy
Upload the contents of this folder to a static hosting provider such as Netlify, Vercel, GitHub Pages or any standard web host.

## Notes
- The design is wizarding/fantasy inspired, using the supplied portrait as the hero image.
- The third project, QuestBoard, is clearly marked as a future build concept so it is not presented as past professional work.
- The contact form is frontend-only and opens the visitor's email client via `mailto:`.
